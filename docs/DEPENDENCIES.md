# Dependency Licenses

This is a human-readable compliance reference, not legal advice. The package's own license files and `THIRD_PARTY_NOTICES.md` remain authoritative for their respective works.

## Inventory and Check

Install the lockfile-resolved dependency graph, then inspect production and development dependencies separately:

```bash
pnpm install --frozen-lockfile
pnpm licenses list --prod --json --long
pnpm licenses list -D --json --long
pnpm license:check
```

The internal package/version inventory and review classifications are maintained with the repository's agent-only audit records. `license:check` reads installed package license metadata through pnpm; it does not access the network or make legal compatibility determinations. Only the explicit policy list and exact, documented package exceptions pass.

## Review Policy

The production check accepts the project's explicitly recognized license identifiers: MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, 0BSD, CC0-1.0, and Unlicense. For `AND` expressions every term must be recognized; for `OR` expressions at least one explicitly recognized option must be available. Unknown, unlicensed, copyleft, and custom terms fail unless a package/version/expression-specific review exception is recorded in the checker. The Twitter exceptions also verify that the complete installed Custom License text is present in `THIRD_PARTY_NOTICES.md`.

Development-only licenses are inventoried separately. They do not pass through the production checker and should be reviewed before moving a package into `dependencies`.

## Special Dependencies in the Current Lockfile

- `ua-parser-js@1.0.41` is MIT-licensed. Version 2 was declared `AGPL-3.0-or-later`; the project uses the v1 API required by the analytics collector and tests desktop, mobile, and unknown user agents.
- `twitter-openapi-typescript@0.0.56` and its transitive `twitter-openapi-typescript-generated@0.0.40` declare `custom license or AGPL-3.0-or-later`. This project records the Custom License as its selected option in the checker. The exact notice, copyright, redistribution condition, and behavioral restriction are included in `THIRD_PARTY_NOTICES.md`; this is not an MIT license.
- `json-schema@0.4.0` declares `(AFL-2.1 OR BSD-3-Clause)`. Its package license text permits choosing either option; the production checker recognizes the explicit BSD-3-Clause branch and does not treat AFL-2.1 itself as an allowed identifier.

The development graph also reports `argparse` (Python-2.0), `caniuse-lite` (CC-BY-4.0), `lightningcss` (MPL-2.0), and `minimatch` (BlueOak-1.0.0). Keep these development-only unless their licenses receive a separate production review.

## Notices

`THIRD_PARTY_NOTICES.md` retains notices for code and data copied or adapted into this repository, including shadcn-admin, the Twitter packages' selected custom license, and Natural Earth attribution. It is not an autogenerated license bundle for every installed package.
